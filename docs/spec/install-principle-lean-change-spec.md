## 改什么（现状 → 期望）

现有依赖与安装检查未明确要求安装流程跨平台，也未要求安装位置可确定。新增 P0 检查项，要求适用时覆盖各主流平台，并优先将依赖安装在 skill 安装目录内的专属子目录。

## 为什么

避免 skill 因仅适配单一操作系统、依赖被装入不确定位置或污染全局环境而无法稳定复用和分发。

## 具体改动点

- `skill/references/review-checklist.md`：新增 3.6 跨平台与安装位置检查，并更新安装检查适用范围。
- `skill/SKILL.md`：将 3.6 纳入审查流程和大技能并行审查职责。
- `README.md`、`README_zh.md`：列出新的安装检查能力。

## 影响范围 / 不做什么

- 影响：仅新增 skill-reviewer 对含安装步骤 skill 的审查标准。
- **不做**：不规定所有程序必须支持所有操作系统；无法跨平台时，要求明确声明支持范围和替代路径。

## 验收标准（可判定，含边界/失败用例）

- [x] 安装检查清单包含跨平台支持范围、平台安装位置和 skill 内优先安装位置的可判定要求。
- [x] 主流程在有安装依赖时会执行新检查项，且大技能分支审查不会遗漏该项。
- [x] 中英文 README 均说明新增检查能力。

- [x] 忠实自查：逐条对照上面的验收标准与“不做什么”，未扩展为强制全平台支持。
